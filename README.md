📝 Todo MERN Application

A full-stack **Todo Management Application** built using the **MERN stack** with authentication, role-based access, and a modern UI.

---

 🚀 Live Demo

* **Frontend (Vercel):** [https://todo-mern-frontend.vercel.app](https://todo-mern-frontend.vercel.app)
* **Backend (Render):** [https://todo-mern-backend-u6s6.onrender.com](https://todo-mern-backend-u6s6.onrender.com)

---

🛠️ Tech Stack

### Frontend

* React (Vite)
* Tailwind CSS
* Axios
* React Router
* Framer Motion

### Backend

* Node.js
* Express.js
* MongoDB (Atlas)
* Mongoose
* JWT Authentication
* bcryptjs
* Multer (optional image upload)

### Deployment

* Frontend: **Vercel**
* Backend: **Render**
* Database: **MongoDB Atlas**

---

## ✨ Features

* ✅ User Signup & Login (JWT based)
* ✅ Role-based access (Admin / User)
* ✅ Create, Read, Update, Delete Todos
* ✅ Admin Dashboard
* ✅ Secure APIs
* ✅ Responsive & modern UI
* ✅ Deployed on cloud platforms

## 🧪 API Testing (Postman)

* **POST** `/api/auth/signup`
* **POST** `/api/auth/login`
* **GET** `/api/todos`
* **POST** `/api/todos`
* **PUT** `/api/todos/:id`
* **DELETE** `/api/todos/:id`

JWT token is passed using:

```
Authorization: Bearer <token>
```
